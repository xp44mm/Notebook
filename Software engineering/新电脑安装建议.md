## 四、注意事项

1. **驱动跟随硬件**：新电脑的 CPU/显卡/声卡/网卡品牌型号未知，驱动必须按实际硬件到官网下载（AMD/Intel/NVIDIA/Realtek/主板厂商），不能照搬本机。
2. **不需要安装的**：本机原有的 360 残留目录、NVIDIA PhysX 残留、Adobe Flash Player 9 已在 2026-09-05 清理；新机**无需安装**这些历史残留。
3. **老软件兼容性**：AutoCAD 2008 是很老的版本，在 Win10/11 新系统上可能安装失败或不稳定，若新机确实需要，建议评估升级版本或使用兼容模式。
4. **正版与授权**：SOLIDWORKS、AutoCAD、Microsoft 365 企业应用版都需要正版授权/企业账号，新机安装时准备好对应的序列号或登录账号。
5. **版本取舍**：清单按"尽量与当前一致"列出；实际安装时开发类软件建议顺手升级到当前最新版（如 VS Code、Node、.NET），不影响工程兼容性的一般可保持最新。
6. **备份软件配置**：像 Beyond Compare、ConEmu、VS Code 的配置（如 settings.json、会话方案），可从当前电脑导出后导入新机，能更快还原习惯。
7. **数据库与开发数据**：SQL Server LocalDB 的本地数据库文件（.mdf）如需迁移，可一并拷贝。

## 五、装机后可顺手做的

- 用 `winget` 包管理器可批量安装很多软件，例如：`winget install --id Microsoft.VisualStudio.2022.Professional`（按需）。
- 系统更新到最新补丁后，再装驱动和运行库，减少兼容问题。
- 新机若是固态硬盘且内存 16GB 以上，体验会优于当前机器（当前仅约 14GB 内存）。

## 八、哪些软件可以交给豆包工作安装

> 豆包工作是在你授权下操作电脑/浏览器帮你完成安装的 Agent（官方口径），并非应用商店。能否顺利安装取决于软件安装包是否自动化友好。以下按本机清单分三档。

### ✅ 适合交给豆包工作安装（有官方安装包、向导简单、几乎无需交互）

| 类别 | 软件 |
| --- | --- |
| 开发工具 | Git、Node.js、VS Code、ConEmu、Beyond Compare |
| 日常工具 | WinRAR、PotPlayer、qBittorrent、迅雷、百度网盘、Mp3tag、Balabolka、MarkText、剪映、豆包 |

### ⚠️ 可装但需你中途接手（安装可自动化，登录/激活环节由你操作）

| 软件 | 需你操作 |
| --- | --- |
| 微信 | 扫码登录 |
| 剪映 | 登录账号 |
| Typora | 输入许可证 |
| 豆包 / 豆包工作 | 登录 |

### ❌ 建议手动安装

| 软件 | 原因 |
| --- | --- |
| Visual Studio Professional 2026 | 安装器大、需勾选工作负载、可能需微软账号 |
| Microsoft 365 企业应用版 | 需企业账号激活 |
| SOLIDWORKS 2025 | 需序列号 + 多组件 + 授权 |
| AutoCAD 2008 | 老软件兼容性处理 |
| 各类驱动（芯片组/显卡/声卡/网卡/蓝牙/打印机） | 需按新机硬件选择，官网下载更稳，装完常需重启 |

### 使用建议

1. **前提**：新电脑装好豆包工作客户端（doubao.com/work），用「本地电脑」模式运行，期间保持开机联网、客户端在线。
2. **指令示例**："帮我在新电脑上安装 Git、Node.js、VS Code 和 VC++ 运行库，全部从官网下载官方安装包，用静默安装。"
3. **可提速**：若豆包工作支持调用 winget，可用 `winget install` 批量静默安装第一档软件（Git、Node、VS Code、PotPlayer 等均在源内）。
4. **红线**：账号密码、许可证密钥、企业授权等由本人输入，不要让豆包工作经手；涉及登录、关键数据的操作先确认范围。
5. **驱动与大型专业软件**：建议手动，尤其驱动需按新机硬件到官网选择。
